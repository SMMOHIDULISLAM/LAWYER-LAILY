# ⚖️ LAWYER LAILY

Bangladesh legal knowledge platform with two planned products: an AI legal agent and an AI-powered mobile application.

## Run the initial web prototype

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

This first application is a **legal source directory**, not yet a trained AI, comprehensive case database, or mobile app. RAG, full-text ingest, and court dashboards remain development milestones.

- [Project scope](docs/PROJECT_SCOPE.md)
- [Legal source registry](data/sources.json)

## Accuracy principles
Never fabricate statutes, articles, case citations or dates. Check the effective text and status of each law against official sources. Respect privacy, restricted court portals, institutional subscriptions, and publication licences.
